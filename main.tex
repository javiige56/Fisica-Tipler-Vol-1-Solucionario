\section{Capítulo 1. Medida y vectores}

\subsection{Problemas conceptuales}

\begin{enumerate}
    \item ¿Cuál de las siguientes magnitudes físicas \textbf{no} es una de las fundamentales del Sistema Internacional (SI)? 

    \begin{enumerate}
        \item Masa.
        \item Longitud.
        \item Energía.
        \item Tiempo.
        \item Todas ellas son magnitudes físicas fundamentales.
    \end{enumerate}

    \textbf{Respuesta correcta:} c)

    \item Al hacer un cálculo, el resultado final tiene las dimensiones de $m/s$ en el numerador y $m/s^2$ en el denominador. ¿Cuáles son las unidades finales?

    \begin{enumerate}
        \item $m^2/s^3$
        \item $1/s$
        \item $s^3/m^2$
        \item $s$
        \item $m/s$
    \end{enumerate}

    \textbf{Respuesta correcta:} d)

    \item El prefijo giga significa: 

    \begin{enumerate}
		\item $10^3$
		\item $10^6$
		\item $10^9$
		\item $10^12$
		\item $10^15$
    \end{enumerate} 

	\textbf{Respuesta correcta:} c)

	\item El prefijo mega significa:

    \begin{enumerate}
		\item $10^{-9}$
		\item $10^{-6}$
		\item $10^{-3}$
		\item $10^{6}$
		\item $10^{9}$
    \end{enumerate} 

	\textbf{Respuesta correcta:} d)

	\item Demostrar que un pie equivale a 30,48cm. ¿Cuántos centímetros hay en una milla?

	\item El número 0,0005130 tiene \_\_\_\_ cifras significativas.

	\begin{enumerate}
		\item una
		\item tres 
		\item cuatro
		\item siete
		\item ocho
	\end{enumerate} 

	\textbf{Respuesta correcta:} c)

	\item El número 23,0040 tiene \_\_\_\_ cifras significativas.

	\begin{enumerate}
		\item dos
		\item tres
		\item cuatro
		\item cinco
		\item seis
	\end{enumerate}

	\textbf{Respuesta correcta:} e)

	\item Una fuerza tiene dimensiones de masa por aceleración. La aceleración tiene dimensiones de velocidad dividida por el tiempo. La presión es una fuerza dividida por una 		área. ¿Cuáles son las dimensiones de la presión?

	\textbf{Respuesta correcta}
	
	La relación entre las magnitudes anteriores es
	$$P=\frac{F}{A}=\frac{ma}{A}=\frac{m\frac{v}{t}}{A}$$
	Tomando la ecuación de dimensiones en la igualdad anterior
	$$[P]=\frac{[m]\frac{[v]}{[t]}}{[A]}=\frac{M \frac{LT^{-1}}{T}}{L^2}=\frac{MLT^{-2}}{L^2}=ML^{-1}T^{-2}$$
	Así, la unidad de presión es el \textbf{Pascal}
	$$1 Pa = 1 kg \cdot m^{-1} \cdot s^{-2}$$

	\item Verdadero o Falso: para multiplicar dos magnitudes es condición necesaria que tengan las mismas dimensiones

	\textbf{Respuesta correcta:} Falso. Por ejemplo, para obtener la fuerza mediante la segunda Ley de Newton, se multiplica una masa por una aceleración (que no tienen las 	mismas dimensiones).

	\item Un vector tiene la componente $x$ negativa y la componente $y$ positiva. Su ángulo medio en la dirección contraria a las agujas del reloj desde el eje $x$ está:

	\begin{enumerate}
		\item Entre cero y 90 grados.
		\item Entre 90 y 180 grados.
		\item Más allá de los 180 grados
	\end{enumerate}
	
	\textbf{Respuesta correcta:} Entre 90 y 180 grados.
    
\end{enumerate}
